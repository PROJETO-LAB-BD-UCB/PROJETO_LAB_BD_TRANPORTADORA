# Sistema de Transportadora e Entregas

Projeto desenvolvido para a disciplina de Laboratório de Banco de Dados
da Universidade Católica de Brasília - UCB.

## Objetivo

Desenvolver um banco de dados para gerenciamento das operações de uma
transportadora, contemplando clientes, motoristas, veículos, pedidos,
entregas e demais informações relacionadas ao processo logístico.
